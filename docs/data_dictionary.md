# Data Dictionary

| Field | Meaning |
|---|---|
| tpep_pickup_datetime | Trip pickup timestamp |
| tpep_dropoff_datetime | Trip drop-off timestamp |
| passenger_count | Passenger count |
| trip_distance | Trip distance |
| PULocationID | Pickup taxi-zone ID |
| DOLocationID | Drop-off taxi-zone ID |
| fare_amount | Metered fare |
| tip_amount | Tip amount |
| tolls_amount | Toll amount |
| total_amount | Total charged amount |
| payment_type | Payment method code |

Derived fields include pickup_date, pickup_hour, trip_duration_minutes, revenue_per_mile and average_speed_mph.
Always verify the current TLC documentation before interpreting coded fields.
